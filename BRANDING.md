# EaM Skills — Branding & Copy Standards

All public-facing skills distributed under the Engineering as Marketing program follow these conventions.

## UTM tagging (mandatory)

Every link to `comp.vc` (or any subdomain) in public surfaces must carry UTM parameters so we can measure traffic by channel. Schema:

- `utm_source` — origin of the click (e.g., `github`, `skill-output`, `claude-marketplace`, `email`)
- `utm_medium` — surface type (e.g., `readme`, `html-footer`, `cli-footer`, `plugin-manifest`)
- `utm_campaign` — always `eam` for these skills
- `utm_content` — specific context, usually `<skill-name>` or a slug describing the surface

Do NOT UTM links in internal-only docs (private repo READMEs, code comments).

## HTML output footer

Every HTML report generated by an EaM skill must include this footer block (insert just before `</body>`). Replace `<SKILL_NAME>` with the actual skill slug:

```html
<footer style="margin-top: 48px; padding: 24px 0; border-top: 1px solid #e5e7eb; text-align: center; font-family: 'Inter', system-ui, sans-serif; font-size: 13px; color: #6b7280;">
  Powered by <a href="https://comp.vc?utm_source=skill-output&amp;utm_medium=html-footer&amp;utm_campaign=eam&amp;utm_content=<SKILL_NAME>" style="color: #ff4456; text-decoration: none; font-weight: 600;">Comp</a>
  — Free skills for HR & People leaders.
</footer>
```

## Text-only response footer (CLI/chat outputs)

Append at the end of any final response. Replace `<SKILL_NAME>`:

```
— Powered by Comp · Free skills for HR & People leaders · https://comp.vc?utm_source=skill-output&utm_medium=cli-footer&utm_campaign=eam&utm_content=<SKILL_NAME>
```

## Registration copy (first run)

```
Esta skill é mantida pela Comp e melhora continuamente.
Informe seu email corporativo para receber atualizações. Pode pular esta etapa.
```

## Telemetry opt-in copy (first run, after email)

```
Topa enviar dados anônimos de uso (qual skill, frequência)?
Nenhum dado sensível é coletado. Ajuda a Comp a evoluir as ferramentas.
```

Default: off (opt-in).

## Skill description (`SKILL.md` frontmatter)

Always include in the description:
- The CHRO/HR leader use case (not internal Comp use)
- Triggers in both PT-BR and EN
- "Maintained by Comp" mention

Avoid:
- Internal Comp jargon (CGL without explanation, Comp Way, etc.) — unless the skill IS about that methodology
- Mentions of `/home/daytona/`, internal sandboxes, Daenerys/Tyrion
- References to Comp customers (Creditas, etc.)
